# Tradução da interface

O PGStudio tem a interface em inglês (como o SSMS) e em português do Brasil.
O idioma vem de Tools > Options > Environment > International Settings; o
padrão, "Same as system", segue o idioma do sistema. A troca vale na hora,
sem reiniciar. `PGSTUDIO_LANG=pt-BR` (ou `en`) força um idioma, útil para
screenshots.

## Como escrever texto da interface

O texto em inglês continua no código e é a chave da tradução, como no gettext
(crate `pgstudio-i18n`):

```rust
use pgstudio_i18n::{tr, trf};

ui.button(tr("Cancel"));
self.status = tr("No query window is open.").to_string();
self.output.push(trf!("Connected to {name}.", name = server));
```

- `tr("texto")` traduz. Aceita texto dinâmico (o rótulo de um comando, um
  item de uma tabela `const`), mas aí o teste não acha a chave sozinho: cubra
  a tabela num teste com `pgstudio_i18n::has_translation`, como em
  `menus.rs`.
- `trf!("... {nome} ...", nome = valor)` para texto com valores. Use
  marcadores nomeados, nunca `{}`; a tradução pode mudar a ordem.
- Plural: duas chaves (`"Saved 1 row to {path}."` e
  `"Saved {n} rows to {path}."`), não `row{s}`.
- `trc("contexto", "texto")` quando a mesma palavra em inglês precisa de
  traduções diferentes (`msgctxt` no catálogo).
- Rótulos de `CommandId` já saem traduzidos por `CommandId::label()`; a chave
  é o texto do `commands!`.

Cada texto novo precisa de uma entrada em
[`crates/i18n/locales/pt-BR.po`](../crates/i18n/locales/pt-BR.po):

```
msgid "Connected to {name}."
msgstr "Conectado a {name}."
```

## O que não se traduz

Palavras-chave e trechos de SQL, nomes de objetos, tipos e funções do
PostgreSQL, nomes de produto (PGStudio, PostgreSQL, IntelliSense) e as
mensagens do servidor (que já vêm no idioma do `lc_messages` dele). Para um
texto desses num widget, ponha `// i18n-ignore` na linha ou na de cima.

## Glossário

Os termos seguem o SSMS e o Visual Studio em português:

| Inglês | Português |
| --- | --- |
| Object Explorer | Pesquisador de Objetos |
| Registered Servers | Servidores Registrados |
| Query | Consulta |
| Results to Grid / Text / File | Resultados em Grade / Texto / Arquivo |
| Estimated / Actual Execution Plan | Plano de Execução Estimado / Real |
| Activity Monitor | Monitor de Atividade |
| Schema Compare | Comparação de Esquemas |
| Back Up / Restore Database | Fazer Backup / Restaurar Banco de Dados |
| Refresh | Atualizar |
| Ready | Pronto |
| Auto Hide | Ocultar Automaticamente |
| Table / View / Column / Index | Tabela / Exibição / Coluna / Índice |
| Schema | Esquema |
| Role | Role (o termo do PostgreSQL) |
| Options | Opções |

## Os testes

`cargo test -p pgstudio-i18n --test coverage` lê o código do workspace e
falha quando:

1. um texto em `tr`/`trf!`/`trc`/`tr_noop` não tem tradução no catálogo;
2. um texto visível vai direto a um widget do egui (`ui.label("...")`,
   `Button::new("...")`, `self.status = "..."`...) sem `tr`. Os arquivos
   ainda não convertidos estão na lista `PENDING` do teste, que só diminui.
